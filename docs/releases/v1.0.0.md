# Storix 1.0.0

This is the first release of **Storix**, an open-source backup agent for Windows (with a Linux agent). A Windows service runs your backup jobs on a schedule, and **Storix Manager** is where you set them up, follow them and restore from them. Storix backs up websites, files and databases, encrypts them, and sends them wherever you keep backups.

## Downloads

| File | What it is |
|---|---|
| `Storix-1.0.0-x64.msi` | Installer for Windows 10/11 and Windows Server 2016+. Installs and starts the service and adds **Storix Manager** to the Start menu. |
| `Storix-1.0.0-x64-portable.zip` | The same programs without an installer. Install the service from the **Service** tab. |
| `storix-1.0.0-x64.exe` | One self-contained file for disaster recovery: verify, browse and restore backups on any Windows machine, with no installation. |
| `storix-1.0.0-linux-x64.tar.gz` | Headless Linux agent (systemd) with the CLI. |
| `SHA256SUMS.txt`, `SHA256SUMS-linux.txt` | Checksums of every file. |

No .NET installation is needed: all builds are self-contained. MongoDB backups need [MongoDB Database Tools](https://www.mongodb.com/try/download/database-tools) (`mongodump`).

> The binaries in this release are not code-signed, so Windows SmartScreen may warn before the installer runs. Check the file against `SHA256SUMS.txt`, then choose **More info → Run anyway**.

## Features

### What it backs up
- **Files and folders**, with exclude patterns and **Volume Shadow Copy** for open and locked files.
- **SQL Server**: full, differential and transaction-log backups, with a point-in-time restore that rebuilds the chain.
- **MongoDB** (`mongodump`, optionally `--oplog`), **PostgreSQL**, **MySQL / MariaDB**, **Redis** and **SQLite**.
- **Windows server configuration** (IIS, registry keys, scheduled tasks, certificates), **Docker volumes** and **Hyper-V virtual machines**.

### Where it sends backups
- **Storage and file servers**: local or network folder (UNC, with its own credentials), FTP/FTPS, SFTP and WebDAV (Nextcloud, NAS).
- **Cloud storage**: Google Drive, Amazon S3 and S3-compatible storage (Cloudflare R2, Wasabi, Backblaze B2, MinIO, Arvan…), Azure Blob, Dropbox and OneDrive / SharePoint.
- **rclone**, which adds 40+ more providers.
- **Telegram / Bale** as an archive-only disaster copy in a private channel:
  - Files up to 47 MB are sent as one document, with a pinned catalog.
  - An optional **Cloudflare Worker relay** helps when the server cannot reach Telegram.
- A **setup guide** for every destination: where to create the credentials, where to sign in, and the pitfalls.

### Processing
- Compression: ZIP or **zstd**.
- **AES-256 encryption**, keyed from a password or from an **RSA-4096 public key** so the private key stays offline.
- **Deduplication** ("incremental forever": FastCDC chunks, zstd, AES-256-GCM).
- **Incremental** file backups with automatic full backups.
- Splitting into volumes.
- A SHA-256 checksum for every backup.

### Reliability
- **Retries** with back-off and **resumable uploads** (FTP, SFTP, Google Drive, S3 multipart).
- Verification after every backup; SQL Server backups can also be checked with `RESTORE VERIFYONLY`.
- **Retention**: keep the last N backups, delete backups older than N days, and **GFS** rules (daily/weekly/monthly/yearly). The newest backup is never deleted.
- **S3 Object Lock** for immutable backups.
- **Scheduled restore drills**:
  - SQL Server is restored into a temporary database and checked with `DBCC CHECKDB`.
  - MongoDB is checked with `mongorestore --dryRun`.
- Crash recovery, catch-up of missed runs, a circuit breaker for failing destinations and a free-space check.
- **Copy jobs (3-2-1)**, job chains, pre/post commands, bandwidth limits and upload windows.

### Storix Manager
- **Template gallery** with 25 ready-made jobs as cards, by category: websites (IIS, WordPress, Linux), databases, file servers, server and VMs, and off-site copies.
- **Set up several backups at once**:
  - Tick IIS websites detected on the server, MongoDB or SQL Server databases listed from the server, or folders.
  - Choose the destination, schedule and password once; you get one job per item, with staggered start times.
- **Run now**, pause/resume and cancel. The Jobs list shows a live status and friendly times.
- **Dashboard**: success rate, space per job and destination, growth and a 30-day forecast.
- **Restore wizard**:
  - Restore from a destination or from a file, with single-file restore from a small encrypted index.
  - Database restore for SQL Server and MongoDB.
- **English and Persian** (right-to-left), light, dark or system theme, a tray icon with status, and an **audit log** of every change.
- Import/export of the configuration, with secrets removed or protected by a passphrase.
- A daily update check that verifies the checksum and signature before installing.

### Monitoring
- Notifications by e-mail, HMAC-signed webhooks, Telegram, Bale, Slack, Teams and Discord.
- A dead man's switch alert, and healthchecks.io and Uptime Kuma pings.
- Prometheus `/metrics`, Windows Event Log entries and OpenTelemetry traces.

### Command line and automation
- `storix run | history | status | cancel`, and `storix run --dry-run`.
- **Config as code**: `storix validate` / `storix apply` with `${env:NAME}` placeholders for secrets.
- `storix verify | list-files | restore` for disaster recovery, and `storix keygen`.
- **Plugins**: your own sources and destinations as .NET class libraries.

## Getting started

1. Install `Storix-1.0.0-x64.msi` and open **Storix Manager**.
2. Click **New** (Ctrl+N) and choose a template, or **Set up several backups at once**.
3. Add a destination; its setup guide shows where to get the credentials. Then click **Test connection**.
4. Save, click **Run now** and follow the backup in **History**.
5. Keep the encryption password safe: **Processing → Recovery sheet…** prints everything a restore needs.

Full documentation is in the [README](https://github.com/nimatalebi/Storix#readme). Bugs and ideas are welcome in [Issues](https://github.com/nimatalebi/Storix/issues).

## خلاصه به فارسی

**استوریکس ۱.۰.۰** نخستین نسخهٔ این عامل پشتیبان‌گیری متن‌باز برای ویندوز (و لینوکس) است.

- **مبدأها**: فایل و پوشه (با Shadow Copy)، SQL Server (کامل، تفاضلی، لاگ و بازیابی لحظه‌ای)، MongoDB، PostgreSQL، MySQL، Redis، SQLite، تنظیمات IIS و سرور، Docker و Hyper-V.
- **مقصدها**:
  - پوشه یا شبکه، FTP، SFTP، گوگل‌درایو، S3 و سرویس‌های سازگار، Azure، Dropbox، OneDrive، WebDAV و rclone.
  - تلگرام و بله به‌عنوان آرشیو اضطراری، با امکان واسط Cloudflare Worker.
- **پردازش**: فشرده‌سازی zstd، رمزنگاری AES-256، حذف تکرار و پشتیبان افزایشی.
- **اطمینان**: تلاش دوباره، ادامهٔ آپلود قطع‌شده، سیاست نگهداری GFS و آزمایش خودکار بازیابی.
- **برنامهٔ مدیریت**:
  - گالری ۲۵ الگوی آماده و راه‌اندازی چند پشتیبان با هم (مثلاً چند سایت و چند دیتابیس MongoDB به گوگل‌درایو).
  - اجرای فوری، داشبورد، ویزارد بازیابی و رابط کامل فارسی با حالت تیره.
- **اعلان‌ها**: ایمیل، تلگرام، بله، Slack، Teams، Discord و وب‌هوک.

برای نصب، فایل `Storix-1.0.0-x64.msi` را دریافت و اجرا کنید.
